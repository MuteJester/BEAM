import { Card, CardGrid, Code } from '@astrojs/starlight/components';

## What BEAM answers

<CardGrid>
	<Card title="How likely is this TCR?" icon="magnifier">
		The exact probability of any CDR3β sequence, including ones never seen before, and
		which residues make it likely or unlikely.
	</Card>
	<Card title="How deeply should I sequence?" icon="setting">
		How many distinct sequences to expect at a given depth, and how many two samples will
		have in common.
	</Card>
	<Card title="How many people share this TCR?" icon="open-book">
		The expected number of repertoires in a cohort that contain a sequence, and the full
		distribution around it.
	</Card>
	<Card title="How different are two repertoires?" icon="random">
		A distance between repertoires that separates differences in sequence length from
		differences in local sequence patterns, and names the patterns.
	</Card>
</CardGrid>

## Install

<Code code="pip install beam-model" lang="bash" />

BEAM runs on Linux and macOS with Python 3.11 to 3.15. It comes with a reference model built
from 38,538 human repertoires, ready to load in one line.

## Install

<Code code="pip install beam-model" lang="bash" />

BEAM runs on Linux and macOS with Python 3.11 to 3.15, and on Windows inside
[WSL](/BEAM/start/installation/#on-windows). It comes with a reference model built
from 38,538 human repertoires, ready to load in one line.

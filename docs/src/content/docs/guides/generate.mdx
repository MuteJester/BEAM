**The question:** what do sequences from this population look like, and can I get new ones to
use as a background or a null set?

## Drawing sequences

`sample` draws sequences **in proportion to their probability**: a sequence twice as
probable is drawn twice as often. Give `length` to draw only sequences of that length.

`seed` chooses the draw: the same seed always gives the same sequences, and **leaving it out
uses seed 0**, so two calls without a seed return the same draws. Pass different seeds for
independent draws, for example two null sets.

## Not every draw is a textbook CDR3

The reference model gives some probability to every sequence of up to 27 residues, including
sequences it has never seen. Most of what it draws has the conserved start and end, but not all:

<Example src="generate/canonical" />

That is a little below the corpus the reference model was built from, in which, according to
the paper's Methods, 99.6% of sequences start with C and 98.6% end with F or W. The model reserves some probability for
sequences it never observed, and some of that goes to non-canonical ones. Filter the draws if
your use needs canonical CDR3s only.

<Aside type="caution" title="Pitfalls">
- **Draws reproduce what the model was built from.** Each draw is one cell drawn independently
  from the population the model describes, so repeats come only from probability. A model built
  from one person's repertoire, weighted by abundance, gives expanded clones high probability,
  and its draws repeat them at roughly their frequency in that repertoire. The reference model
  pools many people, so its draws reflect no one person's clones; a model of unique sequences
  has no clonal structure to reproduce. See
  [Abundance or unique sequences?](/BEAM/explanations/abundance/)
- **A fixed `length` changes the question.** `sample(n, length=12)` draws from the sequences of
  length 12 only. Use it when length is controlled by design, not to imitate a repertoire.
</Aside>

This page takes you from an installed BEAM to your first answer computed over every possible
sequence. Every output below is what the code printed when this page was built.

<Aside type="note" title="The reference model arrives with BEAM 1.0">
The reference model of human TCRβ CDR3s used on this page is published with BEAM 1.0.0,
together with its paper; until then `load_pretrained` cannot download it. Everything else works
today on models built from your own sequences: see
[Building a model from your data](/BEAM/guides/build-a-model/).
</Aside>

<Steps>

1. **Load the reference model.**

   BEAM comes with a model built from 38,538 human TCRβ repertoires. The first call downloads it
   (about 90 MB) and checks it; later calls load it from your disk.

   <Example src="quickstart/load" />

   The model has seen 926,909,993 distinct CDR3β sequences, and uses about 1 GB of memory.

2. **Ask how likely a sequence is.**

   `pseq` gives the probability that one TCR drawn from this population has exactly that CDR3.

   <Example src="quickstart/score" />

   The first two are typical CDR3s, with probabilities around 3 in 100,000. The last is
   implausible, and its probability says so: about 7 × 10⁻²³.

3. **Draw new sequences.**

   `sample` draws sequences in proportion to their probability. The same `seed` gives the
   same sequences; give different seeds for independent draws (without one, the seed is 0).

   <Example src="quickstart/sample" />

4. **Answer a sampling question without simulating.**

   If you sequence 100,000 TCRs from this population, how many *different* sequences will you
   see? BEAM computes the expected number directly, with a guaranteed bound on its error,
   instead of simulating.

   <Example src="quickstart/depth" />

   The first such question takes a minute or two while BEAM prepares the integrals it needs.
   After that, every depth is answered instantly.

</Steps>

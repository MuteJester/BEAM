If BEAM is useful in your work, please cite:

> T. Konstantinovsky and G. Yaari. *A computable probability landscape for T cell receptor
> repertoire sampling and comparison.* (Submitted.)

To cite the software itself, use its DOI,
[10.5281/zenodo.23470065](https://doi.org/10.5281/zenodo.23470065): it always resolves to the latest version, and
each release has its own DOI on Zenodo for citing an exact version.

GitHub's **Cite this repository** button on the
[BEAM repository](https://github.com/MuteJester/BEAM) gives the reference in BibTeX and APA,
from its `CITATION.cff` file.

If you use the reference model, please also cite its Zenodo record (DOI listed by
`BEAM.pretrained_models()`), and the studies whose data it was built from, listed in the
paper's Supplementary Information.

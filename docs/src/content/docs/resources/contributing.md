- **Questions and ideas:** [GitHub Discussions](https://github.com/MuteJester/BEAM/discussions).
- **Bugs:** [GitHub Issues](https://github.com/MuteJester/BEAM/issues), with a short example,
  your BEAM version, Python version and operating system.
- **Security problems:** report them privately, as described in the
  [security policy](https://github.com/MuteJester/BEAM/security/policy).
- **Code and documentation:** see the
  [contributor guide](https://github.com/MuteJester/BEAM/blob/main/CONTRIBUTING.md) for setting
  up a development copy, running the tests and proposing a change.

These pages live in the repository's `docs/` folder; every page has an *Edit page* link at the
bottom.

Every release is listed, with what was added, changed and fixed, in the
[changelog on GitHub](https://github.com/MuteJester/BEAM/blob/main/CHANGELOG.md).

BEAM follows semantic versioning: a patch release (1.0.1) fixes bugs, a minor release (1.1)
adds features without breaking existing code, and only a major release (2.0) may change the
API or the model file format in an incompatible way.
